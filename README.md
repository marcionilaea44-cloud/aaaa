# 装修公司全流程微信小程序

这是一个可直接导入微信开发者工具的示例小程序，覆盖装修公司的核心业务闭环：

1. 咨询获客
2. 预约量房
3. 方案设计
4. 预算报价
5. 施工进度
6. 节点验收
7. 售后维保

## 目录结构

- `app.js / app.json / app.wxss`：全局配置与样式
- `utils/process.js`：流程元数据与示例项目
- `pages/index`：全流程看板与快捷入口
- `pages/appointment`：预约量房表单
- `pages/design`：设计方案展示
- `pages/quote`：预算报价明细
- `pages/progress`：施工进度时间线
- `pages/acceptance`：验收清单与节点确认
- `pages/aftercare`：售后报修与工单记录

## 使用方式

1. 打开微信开发者工具。
2. 选择“导入项目”，目录指向本仓库。
3. 填写测试 `AppID`（或使用无 `AppID` 模式）。
4. 编译后即可体验完整流程。

## 可扩展建议

- 接入云开发数据库，持久化项目、工单和报价。
- 对接企业微信/短信服务，实现节点通知。
- 增加角色权限：客户、设计师、项目经理、监理。
- 增加图片上传与电子签章能力。
