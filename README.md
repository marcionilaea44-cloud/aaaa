# 装修公司全流程微信小程序（示例）

这是一个可直接导入微信开发者工具的装修公司业务全流程小程序模板，覆盖：

1. 咨询与预约量房
2. 方案设计与透明报价
3. 施工进度追踪与监理播报
4. 竣工交付与售后报修

## 目录结构

- `app.json`：全局配置（页面、TabBar）
- `pages/index`：全流程总览首页
- `pages/consult`：客户咨询和预约表单
- `pages/design`：方案套餐和报价示例
- `pages/construction`：施工看板和节点进度
- `pages/delivery`：交付资料与售后工单
- `utils/flow.js`：全流程阶段数据

## 使用方式

1. 打开微信开发者工具。
2. 选择“导入项目”，目录指向本仓库。
3. 填写测试 AppID（或使用自己的 AppID）。
4. 编译后即可体验。
